# {% include icon.html icon="fa-solid fa-microscope" %}研究成果

中心在计算科学理论与算法、智能科学与技术等领域取得了一系列重要成果，在国际顶级期刊和会议上发表高质量学术论文，承担国家重大科研项目，致力于推动计算科学理论与应用的创新发展。

## 近期代表成果

**中心五篇论文入选 NeurIPS 2026。** 研究覆盖视觉-语言表示学习、大语言模型与扩散模型的强化学习对齐，以及具身智能感知。

- **ITO 与 ComCLIP：** 图文预训练与 CLIP 后训练。[ITO 代码](https://github.com/showstarpro/ITO) · [ComCLIP 代码](https://github.com/showstarpro/ComCLIP)
- **ZO-BOLT 与 TMPO：** 零阶强化学习和扩散模型对齐。[TMPO 论文](https://arxiv.org/abs/2605.10983) · [TMPO 代码](https://github.com/mair-lab-hust/tmpo)
- **VideoAfford：** 从人-物交互视频中定位三维可供性。[论文](https://arxiv.org/abs/2602.09638) · [代码](https://github.com/HKUST-GZ-CVL/VideoAfford)
